## 🚀 Projetos

### 📋 Sistema de Solicitações

Aplicação Full Stack para gerenciamento de solicitações de serviços. Possui diferentes níveis de acesso e permite acompanhar solicitações desde a abertura até a conclusão.

O desenvolvimento envolveu autenticação com JWT, controle de permissões, gerenciamento de usuários e responsáveis, recuperação e verificação de e-mail, upload de anexos, filtros, paginação e geração de PDFs.

**Tecnologias:** JavaScript, Node.js, Express, PostgreSQL, HTML, CSS e JWT.

- 🌐 [Acessar aplicação](https://www.sistemasolicitacoes.com.br/login.html)
- 💻 [Código-fonte no GitHub](https://github.com/NinicDev/SistemaSolicitacoes)
